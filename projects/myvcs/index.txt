6:T128a,<h1>MyVCS - A Minimal Git-like Version Control System</h1>
<h2>Overview</h2>
<p>MyVCS is a minimal version control system implemented in Python to help understand the internal workings of Git. This project was created &quot;the hard way&quot; by implementing core Git concepts from scratch, without relying on existing Git libraries.</p>
<p><a href="https://github.com/yogeshp-code/MyVCS">Source Code</a></p>
<h2>Features</h2>
<ul>
<li>Basic Git-like commands: <code>init</code>, <code>add</code>, <code>commit</code>, <code>log</code>, <code>diff</code>, <code>checkout</code>, <code>branch</code>, <code>tag</code>, <code>status</code></li>
<li>SHA-1 based object storage (blobs, trees, commits)</li>
<li>Branching and tagging support</li>
<li>Staging area (index)</li>
<li>Working directory tracking</li>
<li>Commit history visualization</li>
</ul>
<h2>How It Works</h2>
<p>MyVCS mimics Git&#39;s internal architecture with these key components:</p>
<ol>
<li><p><strong>Object Database</strong>:</p>
<ul>
<li>Blobs: Store file contents</li>
<li>Trees: Represent directory structures</li>
<li>Commits: Snapshots with metadata</li>
</ul>
</li>
<li><p><strong>References</strong>:</p>
<ul>
<li>Branches (under <code>refs/heads/</code>)</li>
<li>Tags (under <code>refs/tags/</code>)</li>
<li>HEAD pointer</li>
</ul>
</li>
<li><p><strong>Index</strong>:</p>
<ul>
<li>Tracks staged changes before commit</li>
</ul>
</li>
</ol>
<h2>Installation</h2>
<ol>
<li>Clone this repository</li>
<li>Ensure you have Python 3 installed</li>
<li>Make the script executable:<pre><code class="language-bash">chmod +x myvcs.py
</code></pre>
</li>
</ol>
<h2>Usage</h2>
<p>Basic command structure:</p>
<pre><code class="language-bash">./myvcs.py &lt;command&gt; [options]
</code></pre>

<h2>Implementation Details</h2>
<h3>Core Concepts Implemented</h3>
<ol>
<li><p><strong>Object Storage</strong>:</p>
<ul>
<li>Files are stored as blobs with SHA-1 hashes</li>
<li>Directories are represented as tree objects</li>
<li>Commits point to tree objects and contain metadata</li>
</ul>
</li>
<li><p><strong>References</strong>:</p>
<ul>
<li>Branches and tags are lightweight pointers to commits</li>
<li>HEAD tracks the current branch or commit</li>
</ul>
</li>
<li><p><strong>Staging Area</strong>:</p>
<ul>
<li>Tracks changes before they&#39;re committed</li>
<li>Allows selective commits</li>
</ul>
</li>
</ol>
<h3>Limitations</h3>
<p>This is a learning project with several limitations compared to real Git:</p>
<ul>
<li>No network operations (fetch/push/pull)</li>
<li>Simplified merge conflict handling</li>
<li>Basic error handling</li>
<li>Limited performance optimizations</li>
</ul>
