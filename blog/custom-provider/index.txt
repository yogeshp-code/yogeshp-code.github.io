<h2>How to Build a Custom Terraform Provider (Step-by-Step)</h2>
<p>Let&#39;s jump into the nitty-gritty. Here&#39;s how I created a provider to manage a todo list stored in a JSON file.</p>
<h3>Step 0: Install Prerequisites</h3>
<p><em>(Because We&#39;re Not Mind Readers)</em></p>
<p>Before we begin, ensure you have the following installed:</p>
<ul>
<li>Terraform</li>
<li>Go (Golang): (version &gt; 1.21.0)</li>
<li>Your favorite text editor or IDE (e.g., VS Code)</li>
</ul>
<p><strong>Pro Tip:</strong> Use a version manager like <code>tfenv</code> for Terraform to easily switch between versions during testing.</p>
<h3>Step 1: Project Setup</h3>
<p><em>(The Boring But Necessary Part)</em></p>
<p>Let&#39;s set up our project structure. Think of it like arranging LEGO blocks before building a masterpiece.</p>
<pre><code class="language-bash">mkdir terraform-provider-todo  
cd terraform-provider-todo  
go mod init terraform-provider-todo  
mkdir -p internal/provider  
touch internal/provider/{provider,resource_todo}.go  
touch main.go
</code></pre>
<h3>Step 2: The Main Entry Point (main.go)</h3>
<p>This file is the heart of our provider. It uses Terraform&#39;s Plugin SDK to serve our custom provider.</p>
<pre><code class="language-go">package main

import (
    &quot;github.com/hashicorp/terraform-plugin-sdk/v2/plugin&quot;
    &quot;terraform-provider-todo/internal/provider&quot;
)

func main() {
    plugin.Serve(&amp;plugin.ServeOpts{
        ProviderFunc: provider.Provider})
}
</code></pre>
<h3>Step 3: Provider Definition (internal/provider/provider.go)</h3>
<p>Now, let&#39;s define the provider itself. This is where we specify what our provider will manage and configure the resources for Terraform to work with.</p>
<pre><code class="language-go">package provider

import (
    &quot;github.com/hashicorp/terraform-plugin-sdk/v2/helper/schema&quot;
)

type providerConfig struct {
    StoragePath string
}

func Provider() *schema.Provider {
    return &amp;schema.Provider{
        Schema: map[string]*schema.Schema{
            &quot;storage_path&quot;: {
                Type:     schema.TypeString,
                Required: true,
            },
        },
        ResourcesMap: map[string]*schema.Resource{
            &quot;yogesh_todo_item&quot;: resourceTodoItem(),
        },
        ConfigureFunc: providerConfigure,
    }
}

func providerConfigure(d *schema.ResourceData) (interface{}, error) {
    config := providerConfig{
        StoragePath: d.Get(&quot;storage_path&quot;).(string),
    }
    return &amp;config, nil
}
</code></pre>
<h3>Step 4: The Todo Resource (internal/provider/resource_todo.go)</h3>
<p>Now, let&#39;s get into the meat of it. This step is where we define the resource we want to manage, which in this case is our trusty <code>todo_item</code>. Think of this like building a small module that will allow Terraform to manipulate your todo list.</p>
<pre><code class="language-go">package provider

import (
 &quot;encoding/json&quot;
 &quot;fmt&quot;
 &quot;os&quot;
 &quot;time&quot;
 &quot;github.com/gofrs/flock&quot;
 &quot;github.com/google/uuid&quot;
 &quot;github.com/hashicorp/terraform-plugin-sdk/v2/helper/schema&quot;
)

type TodoItem struct {
 ID        string    `json:&quot;id&quot;`
 Title     string    `json:&quot;title&quot;`
 Completed bool      `json:&quot;completed&quot;`
 CreatedAt time.Time `json:&quot;created_at&quot;`
}

type TodoStorage struct {
 Items []TodoItem `json:&quot;items&quot;`
}

func resourceTodoItem() *schema.Resource {
 return &amp;schema.Resource{
  Create: resourceTodoItemCreate,
  Read:   resourceTodoItemRead,
  Update: resourceTodoItemUpdate,
  Delete: resourceTodoItemDelete,

  Schema: map[string]*schema.Schema{
   &quot;title&quot;: {
    Type:     schema.TypeString,
    Required: true,
   },
   &quot;completed&quot;: {
    Type:     schema.TypeBool,
    Optional: true,
    Default:  false,
   },
   &quot;created_at&quot;: {
    Type:     schema.TypeString,
    Computed: true,
   },
  },
 }
}

// Helper function to load the storage with file locking
func loadStorageWithLock(path string) (*TodoStorage, error) {
 lock := flock.New(path + &quot;.lock&quot;)
 defer lock.Unlock()

 if err := lock.Lock(); err != nil {
  return nil, fmt.Errorf(&quot;failed to acquire file lock: %w&quot;, err)
 }

 if _, err := os.Stat(path); os.IsNotExist(err) {
  return &amp;TodoStorage{Items: []TodoItem{}}, nil
 }

 data, err := os.ReadFile(path)
 if err != nil {
  return nil, err
 }

 var storage TodoStorage
 if err := json.Unmarshal(data, &amp;storage); err != nil {
  return nil, err
 }

 return &amp;storage, nil
}

// Save the storage with updated data
func saveStorage(storage *TodoStorage, path string) error {
 data, err := json.MarshalIndent(storage, &quot;&quot;, &quot;  &quot;)
 if err != nil {
  return err
 }

 return os.WriteFile(path, data, 0600)
}

func resourceTodoItemCreate(d *schema.ResourceData, m interface{}) error {
 config := m.(*providerConfig)
 storagePath := config.StoragePath

 if storagePath == &quot;&quot; {
  return fmt.Errorf(&quot;storage path is not configured&quot;)
 }

 storage, err := loadStorageWithLock(storagePath)
 if err != nil {
  return fmt.Errorf(&quot;failed to load storage: %w&quot;, err)
 }

 item := TodoItem{
  ID:        uuid.New().String(), // Using UUID for guaranteed unique ID
  Title:     d.Get(&quot;title&quot;).(string),
  Completed: d.Get(&quot;completed&quot;).(bool),
  CreatedAt: time.Now(),
 }

 storage.Items = append(storage.Items, item)
 if err := saveStorage(storage, storagePath); err != nil {
  return err
 }

 d.SetId(item.ID)
 d.Set(&quot;created_at&quot;, item.CreatedAt.Format(time.RFC3339))
 return nil
}

func resourceTodoItemRead(d *schema.ResourceData, m interface{}) error {
 config := m.(*providerConfig)
 storagePath := config.StoragePath

 if storagePath == &quot;&quot; {
  return fmt.Errorf(&quot;storage path is not configured&quot;)
 }

 storage, err := loadStorageWithLock(storagePath)
 if err != nil {
  return fmt.Errorf(&quot;failed to load storage: %w&quot;, err)
 }

 for _, item := range storage.Items {
  if item.ID == d.Id() {
   d.Set(&quot;title&quot;, item.Title)
   d.Set(&quot;completed&quot;, item.Completed)
   d.Set(&quot;created_at&quot;, item.CreatedAt.Format(time.RFC3339))
   return nil
  }
 }

 // Returning a more user-friendly error message
 d.SetId(&quot;&quot;)
 return fmt.Errorf(&quot;todo item with ID &#39;%s&#39; not found&quot;, d.Id())
}

func resourceTodoItemUpdate(d *schema.ResourceData, m interface{}) error {
 config := m.(*providerConfig)
 storagePath := config.StoragePath

 if storagePath == &quot;&quot; {
  return fmt.Errorf(&quot;storage path is not configured&quot;)
 }

 storage, err := loadStorageWithLock(storagePath)
 if err != nil {
  return fmt.Errorf(&quot;failed to load storage: %w&quot;, err)
 }

 // We only need the index, so item is not needed
 _, index, err := findTodoItemByID(storage, d.Id())
 if err != nil {
  return err
 }

 storage.Items[index].Title = d.Get(&quot;title&quot;).(string)
 storage.Items[index].Completed = d.Get(&quot;completed&quot;).(bool)

 if err := saveStorage(storage, storagePath); err != nil {
  return err
 }

 return nil
}

func resourceTodoItemDelete(d *schema.ResourceData, m interface{}) error {
 config := m.(*providerConfig)
 storagePath := config.StoragePath

 if storagePath == &quot;&quot; {
  return fmt.Errorf(&quot;storage path is not configured&quot;)
 }

 storage, err := loadStorageWithLock(storagePath)
 if err != nil {
  return fmt.Errorf(&quot;failed to load storage: %w&quot;, err)
 }

 // We only need the index, so item is not needed
 _, index, err := findTodoItemByID(storage, d.Id())
 if err != nil {
  return err
 }

 storage.Items = append(storage.Items[:index], storage.Items[index+1:]...)
 if err := saveStorage(storage, storagePath); err != nil {
  return err
 }

 return nil
}

// Helper function to find TodoItem by ID
func findTodoItemByID(storage *TodoStorage, id string) (*TodoItem, int, error) {
 for i, item := range storage.Items {
  if item.ID == id {
   return &amp;item, i, nil
  }
 }
 return nil, -1, fmt.Errorf(&quot;todo item with ID &#39;%s&#39; not found&quot;, id)
}
</code></pre>
<h3>Step 5: Build and Install the Provider</h3>
<p>Now that we&#39;ve got our provider and resource definitions in place, it&#39;s time to build the provider and install it locally. This is like assembling your custom tool and setting it up for use, ready to manage your todo list.</p>
<pre><code class="language-bash">go get github.com/google/uuid
go get github.com/gofrs/flock
go mod tidy
go build -o terraform-provider-todo

# Create a local plugin directory where Terraform will look for the provider
mkdir -p ~/.terraform.d/plugins/local.providers/local/todo/1.0.0/linux_amd64

# Copy the built provider to the local plugin directory
cp terraform-provider-todo ~/.terraform.d/plugins/local.providers/local/todo/1.0.0/linux_amd64/
</code></pre>
<h3>Step 6: Use Your Shiny New Provider!</h3>
<p>The moment of truth has arrived! It&#39;s time to use the custom provider you&#39;ve just created. Let&#39;s put it to the test and see it in action.</p>
<h4>i) Create a new directory for your Terraform configuration:</h4>
<pre><code class="language-bash">mkdir todo-project
cd todo-project
</code></pre>
<h4>ii) Create provider.tf:</h4>
<p>In this file, we define our provider configuration:</p>
<pre><code class="language-hcl">terraform {
  required_providers {
    todo = {
      source = &quot;local.providers/local/todo&quot;
      version = &quot;1.0.0&quot;
    }
  }
}

provider &quot;todo&quot; {
  storage_path = &quot;todos.json&quot;
}
</code></pre>
<p>This tells Terraform where to find our custom provider and the version we&#39;re using. Also, we specify the storage path for our todo list (which will be a JSON file).</p>
<h4>iii) Create main.tf:</h4>
<p>Here, we&#39;ll define a couple of todo items to manage:</p>
<pre><code class="language-hcl">resource &quot;yogesh_todo_item&quot; &quot;eternal_deployment&quot; {
  title     = &quot;Tackle that Terraform task my manager assigned months ago, because &#39;It&#39;ll be quick, trust me&#39; 🤔&quot;
  completed = false
}

resource &quot;yogesh_todo_item&quot; &quot;blog_writing&quot; {
  title     = &quot;Write a blog about custom providers because my manager casually said, &#39;Do something out of the box,&#39; and I thought... why not? 🧠💡&quot;
  completed = true
}

# For those extra sprint items that keep coming
resource &quot;yogesh_todo_item&quot; &quot;reality_check&quot; {
  title     = &quot;Remind manager that &#39;quick 5-minute fixes&#39; actually take 5 hours&quot;
  completed = false
}

# The classic one
resource &quot;yogesh_todo_item&quot; &quot;documentation&quot; {
  title     = &quot;Update documentation (Just kidding, we all know this will never be completed)&quot;
  completed = false
}
</code></pre>
<p>Now you can run:</p>
<pre><code class="language-bash">terraform init
terraform plan
terraform apply -parallelism=1
</code></pre>
<p><strong>Note:</strong> My app is not yet optimized to handle parallel resources, so please bear with me while I work on improving this.</p>
<p>And voilà! 🎉 You&#39;ve just created a working Terraform provider that manages todo items in a JSON file. Is it practical? Maybe not. But is it cool? Absolutely! 😎</p>

<h2>Common Pitfalls</h2>
<p><em>(Or: Things That Will Test Your Patience)</em></p>
<ul>
<li><strong>State Conflicts:</strong> Directly modify the JSON file, and Terraform will throw a tantrum akin to someone rearranging your perfectly organized desk. Not fun.</li>
<li><strong>Concurrent Access:</strong> This example doesn&#39;t handle multiple Terraform runs accessing the file simultaneously. Debugging this will make you question life choices at 2 AM.</li>
<li><strong>Error Handling:</strong> Let&#39;s just say our current approach to errors is… &quot;minimalist.&quot; Definitely room for improvement here.</li>
</ul>
<h2>Pro Tips</h2>
<p><em>(That I Learned the Hard Way)</em></p>
<ul>
<li><strong>Testing is a Must:</strong> Write tests. Future-you will thank present-you.</li>
<li><strong>Document Everything:</strong> Pretend you&#39;re writing for someone who thinks Terraform is a new Marvel superhero.</li>
<li><strong>Versioning:</strong> Breaking changes without versioning is like showing up to a meeting unprepared - awkward for everyone.</li>
</ul>
